# MyCompTech

MyCompTech adalah landing page edukasi teknologi berbahasa Indonesia. Halaman memperkenalkan konsep komputer, coding, dan keamanan digital untuk pelajar melalui bagian pengenalan, navigasi, dan konten teknologi.

## Isi repositori

Semua source halaman berada di direktori `my-company/`:

- `my-company/index.html` — markup halaman
- `my-company/style.css` — styling
- `my-company/script.js` — JavaScript
- `my-company/assets/` — aset gambar dan media

## Teknologi

- HTML, CSS, dan JavaScript
- Bootstrap CSS dari CDN
- Google Fonts dan Animate.css dari CDN

## Jalankan secara lokal

Tidak perlu instalasi npm untuk melihat halaman statis ini.

1. Clone atau unduh repositori.
2. Buka `my-company/index.html` di browser.

Atau jalankan server statis dari direktori root:

```bash
python -m http.server 8000
```

Lalu buka [http://localhost:8000/my-company/](http://localhost:8000/my-company/).

Akses internet diperlukan untuk memuat pustaka yang dirujuk dari CDN. Repositori ini tidak memiliki script build atau test npm.
